# ChronoSoothe Usability Pilot Kit

Version: 0.1  
Date: 2026-06-04  
Status: Small private beta protocol, not a clinical study

## Purpose

This pilot tests whether users can understand and safely complete a ChronoSoothe self-care ritual. It does not test whether the product treats disease and must not be described as a clinical efficacy study.

The study question is:

> Can users understand the timing recommendation, locate the point, complete a gentle 60-second acupressure ritual, and understand the safety boundary?

## Recommended Pilot Size

Start small:

- Round 1: 5 users
- Round 2: 10 users after copy and UX fixes
- Round 3: 20-30 users only after expert review and safety wording are stable

Five users are enough to reveal major usability confusion. Ten users can produce early directional adherence and comprehension data.

## Participant Criteria

Include:

- adults age 18+
- able to read English or Chinese version being tested
- understands this is educational self-care, not medical care
- willing to spend 3-5 minutes per day for 7 days

Exclude or advise professional care first:

- severe chest pain
- trouble breathing
- fainting
- stroke-like symptoms
- major injury
- active infection, wound, swelling, fracture, or unexplained numbness near the point area
- pregnancy without clinician guidance for points involving caution areas
- any serious or rapidly worsening symptom

## Consent Script

Use this plain-language script before testing:

```text
ChronoSoothe is an educational wellness prototype. It does not diagnose or treat disease. It does not provide acupuncture, needling, moxibustion, or medical advice. You will be asked to view a time-based acupressure recommendation, locate a point using an image, apply gentle pressure only if comfortable, and answer a few usability questions. Stop immediately if you feel pain, numbness, dizziness, distress, or anything unusual. Seek professional care for serious or worsening symptoms.
```

## Study Flow

| Step | User Action | Data Collected | Success Signal |
|---|---|---|---|
| 1 | Open app and choose language | language, device | user reaches Today page |
| 2 | Confirm or skip location | location choice, trust concern | user understands longitude/local solar time |
| 3 | Read Today recommendation | comprehension rating | user can name point and action |
| 4 | Open point image | point-location confidence | user can describe where to press |
| 5 | Complete 60-second ritual | completion, interruption | user uses gentle pressure only |
| 6 | Submit post-ritual feedback | pre/post state, discomfort | no unsafe interpretation |
| 7 | Answer short survey | comprehension, trust, confusion | user understands non-medical boundary |

## Daily User Survey

Ask after each session:

| Question | Response Type |
|---|---|
| Did you complete today's ritual? | yes / partly / no |
| How confident were you that you found the right point? | 1-5 |
| How clear was the instruction? | 1-5 |
| Did you understand this was gentle acupressure only? | yes / no |
| Did you feel discomfort, pain, numbness, dizziness, or distress? | yes / no + note |
| Before ritual, how did you feel? | calm / stressed / tired / tense / other |
| After ritual, how did you feel? | calmer / same / worse / unsure |
| What was confusing? | free text |
| What wording felt too medical or too mysterious? | free text |

## End-of-Pilot Survey

Ask after 7 days:

| Question | Response Type |
|---|---|
| How many days did you use it? | 0-7 |
| Would you use this again? | yes / maybe / no |
| Did the app ever feel like it was making a medical claim? | yes / no + note |
| Did the point images help? | 1-5 |
| Did the time-rhythm explanation increase trust or create confusion? | trust / confusion / both / neither |
| Which page was least clear? | Today / Ritual / Rhythm / Body Map / Library |
| What would make this safer or clearer? | free text |

## Metrics to Report

Report only usability and subjective wellness metrics:

- completion rate
- point-location confidence average
- instruction clarity average
- safety-boundary comprehension rate
- number of discomfort reports
- number of users who misunderstood the product as medical care
- most confusing terms
- most requested improvements
- subjective pre/post direction, clearly labeled as self-report

Do not report disease improvement, treatment success, or clinical effectiveness.

## Minimum Success Threshold Before Public Beta

Recommended threshold:

- 80%+ understand "gentle acupressure only"
- 80%+ can locate the point with moderate confidence or better
- 0 serious safety incidents
- 0 users believe the app replaces professional care
- top 3 confusing terms are fixed
- all discomfort reports are reviewed
