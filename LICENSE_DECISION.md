# License Decision

Do not rush the license choice.

ChronoSoothe has several different asset types:

- public documentation
- whitepaper text
- diagrams
- product screenshots
- source-audit templates
- algorithm notes
- future software code
- point images
- source excerpts

These may need different licenses.

## Conservative Starting Point

For the first public release, it is acceptable to publish without a formal license while you collect expert feedback. This means others can read the material, but they do not automatically receive broad reuse rights.

## Possible Future Choices

| Material | Possible license |
| --- | --- |
| Whitepaper and docs | CC BY-NC 4.0 |
| Source-audit templates | CC BY 4.0 or CC BY-NC 4.0 |
| Software code | MIT, Apache-2.0, or proprietary |
| Product screenshots | All rights reserved unless stated |
| Point images | Only publish if rights and consent are clear |

## Recommended Current Wording

Use this until you decide:

```text
Copyright ChronoSoothe Research Group. Public review draft. Redistribution, commercial use, or derivative use requires permission unless a formal license is added later.
```

This is more conservative than open source, but safer while product strategy is still forming.
